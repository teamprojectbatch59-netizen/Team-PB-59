# Hybrid Prompt Attack Detection and Mitigation Framework

This project develops an AI-powered security framework to detect, classify, and mitigate malicious prompts targeting Large Language Models (LLMs). It identifies threats such as prompt injection, jailbreaks, and prompt extraction using Prompt Guard 2, DeBERTa-v3, ModernBERT, and Llama Guard 3.

The framework analyzes detected attacks based on their type, severity, and target component. Harmful prompts are blocked, and suitable security recommendations and mitigation strategies are provided. Safe prompts are processed using Llama 3.2 3B to generate appropriate responses with additional safety checks.

The primary objective is to improve the security, reliability, and responsible use of LLM-based applications through intelligent prompt detection, attack classification, risk analysis, and mitigation.
